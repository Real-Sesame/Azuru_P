# 아주르 프로밀리아 AUTO TEAM MAKER (Azuru_P)

[띵조 AUTO TEAM MAKER](https://real-sesame.github.io/-/)의 아주르 프로밀리아 버전입니다. 보유 캐릭터만 체크하면 **겹치지 않는 1~3파티**를 각인(조율 표식) 수급 · 직업 구성 · 원소 상성으로 자동 편성합니다.
구조는 띵조 ATM · MH_OL과 같습니다(Vite + GitHub Actions 배포).

주소: https://real-sesame.github.io/Azuru_P/

## 기능
- **파티 편성** `/builder` — 1~3파티, 파티별 적 원소 · 메인 고정, 캐릭터 직접 교체(교체하면 그 파티 고정), 📌 고정, 다른 후보, 키보로 각인 1개 보충 옵션, 공유 링크(`?o=<보유id.>&p=<파티수>`), 편성 텍스트 복사
- **캐릭터** `/characters` · `/character/<id>` — 직업 · 속성 · 각인(만드는/소모/필요) · 티어 · 각인을 대 줄 서포터
- **원소 · 각인** `/elements` — 상성표(±25%), 각인 원소별 효과와 공급 · 소모 캐릭터
- **입문 가이드** `/guide`

## 자동 편성 방식 (`src/builder.js`)
1. 보유 캐릭터 + 성림자(항상 보유)로 가능한 3인 조합을 전부 채점합니다.
2. 점수: 메인 딜러의 핵심 각인(필요 각인 + 주 소모 각인)을 동료가 공급하는지, 하이퍼캐리(딜1+서포2) · 밸런스(딜1+브레이커1+서포1) 구성인지, 회복 · 보호막 유무, 적 원소 상성(메인 ±, 서브 소폭), 티어, 공략 추천 편성과 일치 여부.
3. 여러 파티는 서로 겹치지 않는 조합 중 **점수 합이 가장 큰 것**을 고릅니다. 고정한 파티는 그대로 두고 나머지만 다시 계산합니다.
4. 가중치는 `src/data/builder-rules.json`에서만 바꾸면 됩니다.

## 데이터 고치기
```
src/data/meta.json          원소 · 상성표 · 각인 효과 · 직업 라벨 · 출처 · 버전
src/data/characters.json    캐릭터(list) + 주인공(starborn)
src/data/teams.json         공략 추천 3인 편성
src/data/guide.json         입문 가이드
src/data/builder-rules.json 자동 편성 점수표
```
- 새 캐릭터: `characters.json`의 `list`에 추가 → 편성 · 목록 · 상세 페이지에 바로 반영. 필드 설명은 `docs/SCHEMA.md`.
- 고친 뒤 `npm run check`로 참조 오류를 확인합니다. 배포 때도 자동 점검하며 오류가 있으면 배포가 멈춥니다.

## 자동 갱신 (공식 이미지 · 공식 데이터)
`공식 데이터 자동 갱신` 워크플로(`.github/workflows/sync.yml`)가 **하루 두 번(06:41 · 18:41)** 돌고, **Actions → 공식 데이터 자동 갱신 → Run workflow**로 바로 돌릴 수도 있습니다.

| 하는 일 | 내용 |
|---|---|
| 캐릭터 목록 | 한국 공식 사이트(azurpromilia.nexon.com/main)의 캐릭터 배열에서 이름 · 영문명 · 속성 · 직업을 읽어 `characters.json`을 공식 값으로 고침(`official` 표시) |
| 새 캐릭터 | 공식 사이트에 새 캐릭터가 보이면 `"auto": true` 항목으로 자동 추가 → 편성 · 도감에 바로 나옴('자동 추가' 배지) |
| 공식 이미지 | 한국 공식 → 동남아 공식(playpark) 순서로 썸네일 · 일러스트를 받아 **편집**: 썸네일은 여백 자르고(사각 이미지는 원형 마스크) 256px WebP, 일러스트는 1400px WebP. `public/img/index.json`에 목록 기록 |
| 마무리 | 데이터 점검 → 바뀌었으면 커밋 · 재배포 → **`[자동] 데이터 검토 필요` 이슈**에 새 캐릭터 · 바뀐 항목 · 이미지 없는 캐릭터를 정리(검토할 게 없으면 자동으로 닫힘) |

- 사람이 채워야 하는 값(등급 · 각인 · 티어 · 추천 편성)은 이슈를 보고 `characters.json`에 넣고 `"auto": true`를 지우면 됩니다.
- 공식 사이트 구조가 바뀌어 목록을 못 읽으면 데이터는 그대로 두고 이슈에 경고만 남깁니다.
- 새 사이트 구조를 살펴볼 땐 `공식 사이트 조사` 워크플로(`tools/discover.py`)가 이미지 · 스크립트 주소를 실행 로그에 출력합니다.

## 데이터 기준 (중요)
- 2026-11-26 한국 정식 출시 당일 기준. **스킬 · 각인 데이터는 CBT 기준**이고 정식판에서 바뀔 수 있습니다(파괴 직업 상향 예고).
- 미나모토 치요 · 난향자 · 메이플 · 페페의 각인은 속성 표기 기준 **추정**입니다(화면에 '추정' 배지).
- 캐릭터 이미지는 공식 사이트 이미지를 자동 수집 · 편집해 쓰고, 공식 이미지가 아직 없는 캐릭터만 속성 색 이니셜로 표시합니다.

## 배포
1. `main`에 올리면 **사이트 배포** 워크플로가 데이터 점검 → Vite 빌드 → GitHub Pages 배포(1~2분).
2. 처음 한 번만: **Settings → Pages → Source = GitHub Actions**.

## 내 컴퓨터에서 보기
Node.js 설치 후 `npm install` → `npm run dev`.
