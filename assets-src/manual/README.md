# 직접 넣는 공식 이미지

공식 웹사이트에 아직 없는 캐릭터의 공식 이미지(공식 X · 넥슨 공식 커뮤니티 · 게임 화면 등)를 여기에 올리면,
`공식 데이터 자동 갱신` 워크플로가 바로 실행되어 사이트용으로 편집합니다.

| 파일 이름 | 쓰이는 곳 | 자동 편집 |
|---|---|---|
| `<id>.png` / `.jpg` / `.webp` | 상세 페이지 일러스트 | 가로 1400px. 세로 이미지는 흐린 배경을 깔아 16:9 배너로 |
| `<id>-thumb.png` | 카드 · 편성 초상화 | 여백 자르기 · 원형 · 256px. 없으면 일러스트에서 얼굴을 찾아 자동으로 잘라 냄 |

- `<id>`는 `src/data/characters.json`의 `id`입니다. 예: `morwyn.png`, `ruby.jpg`, `luruka-thumb.png`
- 직접 넣은 이미지가 공식 사이트 이미지보다 우선합니다. 빼고 싶으면 파일을 지우세요.
- 원본은 이 폴더에만 있고, 사이트에는 편집본(`public/img/chars/`)만 올라갑니다.

현재 일러스트가 없는 캐릭터 id: ruby (공식 사이트 · GameWith 모두 없음)
